# 04　报价对账与毛利模型

两个问题：**别人为什么便宜一半**、**这个价能挣多少**。都要能用数字回答，而不是"我们的质量好"。

---

## 一、对账三步法

### 第 1 步：把两边的数折到同一口径

常见口径差有四种，任何一种不折算，比出来的差额都是假的：

| 差异 | 表现 | 折算方法 |
|---|---|---|
| 含税 vs 不含税 | 一边 718、一边 1,412 | 按 9% 折算：不含税 = 含税 / 1.09 |
| 含安装 vs 不含安装 | 一边单价"含安装含税"，一边只有设备 | 除以 (1 + 安装率×设备材料占比)，经验系数 **≈1.22** |
| 范围不同 | 一边含机房 90㎡、一边 30㎡ | 逐类对照，不能只看总额 |
| 机电梯度不同 | 一边含首部与滴灌，一边剥离 | 单列机电，出双口径金额 |

经验做法：把对方直接费 **÷1.22**，得到"不含税、不含安装"的可比数。这个系数只是起点，**真正的结论必须来自逐类对照**。

### 第 2 步：逐类对照，找三块大差

按"建筑侧基础设施 / 布线与管路 / 网络与安全 / 视频与安防 / 广播会议展示 / 农业控制 / 农业平台与追溯 / 实施服务"分桶，每桶给"我 / 对方（归一）/ 差 / 一句话原因"。

经验分布：**差的 60%–80% 集中在 3 桶**——机房与平台、布线与管路、软件与实施。剩下的桶通常是平的。

### 第 3 步：给"真实差价"而不是"总额倍数"

正确表达：

```
同范围下我 924 万，对方 830 万，差 94 万（11%），差在防火墙与审计、第三方检测、深化设计、
桥架与摄像机选型；其余 1,050 万是"要不要机房 90㎡、350 路视频、指挥中心与全棚 AI"的选择。
```

错误表达："我们贵 2.4 倍。"

## 二、砍项映射表（把差额变成可选项）

对账的终点不是"谁便宜"，而是"**这些钱买到什么、不要能省多少**"。做法：把差额按主题打包，每包给"直接费 / 含税 / 买回什么"。

示例（我方 1,983 → 对齐 924 的路径）：

| 包 | 内容 | 直接费 | 含税 |
|---|---|---|---|
| B1 机房与承载升级 | 90㎡、12 柜、80kVA、精密空调、气灭、超融合 | 119.65 | 171 |
| B2 指挥中心与入口展示 | 12㎡ LED、拼接、操作台、入口屏 | 28.46 | 41 |
| B3 视频扩容 | 192 → 350 路 | 31.25 | 45 |
| B4 楼控与设备深化 | BA 80 → 420 点、电梯、污水站 | 56.22 | 80 |
| B5 会议研学与直播 | 报告厅、研学教室、第二直播间、沙盘 | 66.81 | 95 |
| B6 农业平台与 AI | 物联网底座、模型、驾驶舱、AI 32 路、区块链 | 100.24 | 143 |
| B7 冷链与车辆 | 冷藏车、预冷间 | 26.80 | 38 |
| B8 自建光缆 | 48 芯 5.2km | 22.54 | 32 |
| B9 等保与检测 | 等保二级、第三方检测 | 12.00 | 17 |
| B10 实施与驻场 | 深化、培训、首季驻场 90 天 | 41.00 | 58 |
| **合计** | — | **504.97** | **720** |

这份表比任何解释都有用：客户看到的是"**我可以在 924 与 1,644 之间选**"，而不是"两家差 1,000 万"。

## 三、成本率与毛利模型

### 成本率经验值（智能化工程，可直接用，改项目时按实际调整）

| 类别 | 成本率 | 毛利率 | 说明 |
|---|---|---|---|
| 设备 | 90% | 10% | 大厂价格透明，靠集采返点 3%–5% |
| 材料 | 85% | 15% | 线缆管件，量大价低 |
| 软件 | 40% | **60%** | 自研或代理；外购则升到 70% |
| 服务 | 55% | **45%** | 深化、检测、培训、驻场，人力为主 |
| 施工安装 | 72% | 28% | 人工 + 辅材 + 机械 + 脚手架 |
| 系统调试 | 65% | 35% | 工程师人力 |
| 项目管理 | 90% | 10% | 项目经理与资料 |
| 措施项目 | 80% | 20% | 临设、安全文明、成品保护 |

### 计算模板

```
毛利 = Σ(各类报价 × (1 − 成本率))          # 暂列金额不计入
毛利率 = 毛利 / 不含税造价

净利 = 毛利
     − 实缴增值税（销项 − 进项，经验为销项的 25%–35%）
     − 附加税（实缴增值税 × 12%）
     − 公司管理费用（不含税造价 × 5%–8%）
     − 财务费用（垫资额 × 占用月数 × 年化 6%）
净利率 = 净利 / 不含税造价
```

### 基准算例（1,983 万级项目）

| 项 | 金额（万元） |
|---|---|
| 不含税造价 | 1,819.13 |
| 成本合计 | 1,338.50 |
| **毛利** | **397.18（22.9%）** |
| 实缴增值税 | 约 48 |
| 附加税 | 约 6 |
| 公司管理费用 6% | 约 109 |
| 垫资利息 | 约 12 |
| **净利** | **约 222（12.2%）** |

区间：毛利 14%–23%，净利 4%–12%，取决于三个变量。

### 三个变量

| 变量 | 乐观 | 悲观 | 对毛利的影响 |
|---|---|---|---|
| 软件是否自研 | 自研（成本率 40%） | 全外购（70%） | ±61 万 |
| 设备采购折扣 | 集采 10% | 无折扣 | ±37 万 |
| 质保与驻场长度 | 1 年、驻场 90 天 | 3 年、驻场 180 天 | ±25 万 |

**结论话术**：`合同 1,983 万，成本约 1,340 万，毛利约 400 万（23%），扣税与公司费用后净利 150–240 万（8%–12%）`。

## 四、报价低≠赚钱：必须提醒领导的三种情形

| 情形 | 表现 | 后果 |
|---|---|---|
| 软件被砍到"模块级" | 平台从 130 万降到 20 万 | 毛利从 23% 掉到 15%，还把最赚钱的部分让出去 |
| 硬件占比过高 | 设备 80% 以上 | 毛利率顶到 10%，且垫资重 |
| 承诺超范围 | 免费 3 年驻场、7×24 到场 | 义务成本吃掉全部毛利，甚至亏损 |

判断句：**一个方案里如果软件与服务占比低于 15%，这个项目基本不赚钱，只能当业绩。**

## 五、含税/不含税与"施工含不含"的答复模板

被问到"你这个价含不含施工"，标准答复结构（三段）：

1. **含**：安装 14%（人工、辅材、机械、接地测试）+ 措施 4%（临设、安全文明、成品保护、二次搬运）+ 调试 5%；
2. **不含**：土建开槽与修补、穿墙套管与防火封堵、设备基础、道路破除恢复、岩石开挖与顶管、夜间与冬雨季增加费；
3. **兜底**：室外管沟单价已含开挖、砂垫层、回填与手孔砌筑；其余按实另计，投标文件需写清。

> 这一句话说不清，后期每一条都会变成变更单上的争议。
