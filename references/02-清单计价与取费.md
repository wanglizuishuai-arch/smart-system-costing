# 02　清单计价与取费

本文件是"钱怎么算"的全部规则。**任何一处口径变化，都要回到这里对一遍。**

---

## 一、取费链（GB/T 50500-2024，智能化工程适用）

```
一 设备费        = 清单内"类型=设备"合价
二 材料费        = 清单内"类型=材料"合价
三 软件费        = 清单内"类型=软件"合价
四 服务费        = 清单内"类型=服务"合价
五 直接费        = 一 + 二 + 三 + 四
六 施工安装费    = (一 + 二) × 14%
七 系统调试费    = (一 + 二 + 三) × 5%
八 项目管理费    = (五 + 六 + 七) × 3%
九 分部分项      = 五 + 六 + 七 + 八
十 措施项目费    = 九 × 4%
十一 其他项目费  = 九 × 5%（暂列金额）
十二 税前造价    = 九 + 十 + 十一
十三 增值税      = 十二 × 9%
十四 含税造价    = 十二 + 十三
```

三条硬规则：

1. **安装费只计设备与材料**——软件与服务不计安装，否则一个 200 万的软件项目会多算 28 万安装费；
2. **调试费覆盖设备+材料+软件**——软件确实要调试，但不产生安装工作量；
3. **不再单列规费**——2024 标准已并入管理费，重复列会被审减。

综合系数（设备材料占直接费 74% 时）≈ **1.404**。这个系数只用于快速估算，正式成果必须逐级算。

## 三、五项交叉校验（出文档前必须全为 0）

| # | 校验 | 左值 | 右值 |
|---|---|---|---|
| 1 | 分类合计 = 直接费 | 设备+材料+软件+服务 | 清单合价合计 |
| 2 | 分部分项 = 直接费+安装+调试+管理 | 逐项相加 | 九 |
| 3 | 税前 = 分部分项+措施+暂列 | 逐项相加 | 十二 |
| 4 | 含税 = 税前 + 增值税 | 十二+十三 | 十四 |
| 5 | 分层/分标段合计 = 含税 | Σ各层 | 十四 |

校验放在 Excel 的"校验"页，用公式实时联动；同时在 `dict` 层用脚本再算一遍——两套算法互证，是防止"公式引错列"的唯一办法。

> 真实事故：安装/调试/管理/措施/暂列/税 六行全为 0，因为公式硬引用了固定单元格，而费率行是动态写入的。肉眼看不出，只有校验列暴露。

## 四、资金控制额与余量

| 概念 | 定义 | 用法 |
|---|---|---|
| 含税造价 | 算出来的数 | 对外报价口径 |
| 控制额 | 业主/公司批准的资金上限 | 取整到 50 或 100 万，**必须 ≥ 含税造价** |
| 余量 | 控制额 − 含税造价 | 变更与涨价的缓冲，通常 3%–6% |

规则：
- 控制额不是合同价，不作自动计取依据；
- 余量 < 3% 时，必须在方案里提示"涨价风险自担"；
- 含可选包时，另设一个控制额（主预算控制额 + 可选包控制额），两个数不许混用。

## 五、可选包（0/1 开关）与重复项扣除

**核心纪律：可选包里的每一项，都必须已从主预算中扣除。**

```
可选包含税 = (主方案中该项直接费 + 增量直接费) × 取费系数
```

三种典型可选包与扣减法：

| 可选包 | 主预算保留什么 | 可选包补什么 | 扣减依据 |
|---|---|---|---|
| 温室机电（遮阳/保温/加温/补光） | 控制器、传感器、执行回路与接线 | 机构本体 + 电机 | 主预算只到"端子"，不含机构 |
| 灌溉机组与田间滴灌 | 施肥机、首部控制柜、阀控、墒情 | 泵组、过滤、母液罐、主管与滴灌末端 | 阀控已计，机组与管网未计 |
| 消防 | 只读接口与联动干接点 | 报警主机、探测器、灭火系统 | 智能化不参与消防逻辑 |
| 展示与 AI | 1 间直播间、数字沙盘、基础 AI 授权 | 第二间、AR 导览、全棚 AI、数字孪生 | 按数量与授权路数扣 |
| 自建光缆 | 运营商初装与备份链路 | 自建 48 芯 + 管道协调 | 二者互斥，只能选一 |

写作要求：每个可选包给"编号 / 名称 / 直接费 / 含税 / 范围 / 重复项已扣除说明"六列，并在正文用一段话解释"为什么它不在主预算"。

## 六、分层建设（投产必建 / 运营配套）

按"什么时候必须做完"分层，比按"系统"分层更贴施工现实：

| 层 | 判据 | 典型内容 | 占比经验值 |
|---|---|---|---|
| 投产必建 | 不与土建/温室同步就会开槽返工，或投产即需运行 | 布线、网络、安防、机房、温室控制、水肥阀控、气象、冷链、追溯、平台 | 90%–95% |
| 运营配套 | 可随房间装修或经营节奏后置 | 会议培训、信息发布屏、研学沙盘、直播间 | 5%–10% |

算法：

```
运营配套直接费 = Σ(会议 + 信息发布 + 研学直播) 各子系统合价
运营配套含税   = fee(运营配套直接费)
投产必建含税   = 含税造价 − 运营配套含税
```

两个层必须加回含税造价，差值应为 0（进校验第 5 项）。

## 七、三种报价口径（同一份清单，三个数）

| 口径 | 取费方式 | 适用 | 与清单法的关系 |
|---|---|---|---|
| 清单计价（本技能主口径） | 逐级取费 + 税 9% | 政府/国企、需报审、需可核验 | 基准 |
| 含税综合单价 + 深化/预备 | 单价内含税含安装，再 +5%+10% | 快速报价、内部比价 | ≈ 清单法 ×0.97–1.02 |
| 三档配置（基础/标准/领先） | 标准版 = 清单法；基础版 = ×0.72；领先版 = +全部可选包 | 给客户选择权 | 派生 |

**三种口径的总额通常落在同一量级（差 1%–3%）**，这是"价格可信"的最强证据；若差 20% 以上，一定是范围或取费错了，回去查。

## 八、常见取费错误

| 错误 | 现象 | 修正 |
|---|---|---|
| 软件计了安装费 | 安装费虚高 10%–20% | 安装基数只取设备+材料 |
| 措施费按直接费算 | 少算 3%–5% | 基数是分部分项（含安装调试管理） |
| 暂列金额被当成利润 | 结算时被扣 | 明确写"业主预备金，不发生应返还" |
| 税率用 13% | 施工服务适用 9% | 建筑服务 9%，货物 13%，混合销售按主业 |
| 控制额 < 含税造价 | 立项即超 | 控制额取整时向上取 |
| 可选包未扣重复项 | 同一台设备计两次 | 每个包附"扣减说明" |
